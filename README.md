# twitter-sentiment-analysis
NLP project analyzing Twitter sentiment using machine learning models and text preprocessing techniques.



## Course Information

This project was developed as part of the **Natural Language Processing (NLP)** course at the University of Jordan.

---

## Objectives

* Preprocess and clean Twitter text data
* Apply sentiment classification techniques
*Compare model performance
*Evaluate results using standard metrics

---

## Models Used

* SVM
* LSTM 
* RoBERTa

---

## Dataset

The dataset used in this project is publicly available on Kaggle:
[https://www.kaggle.com/datasets/jp797498e/twitter-entity-sentiment-analysis/data?select=twitter_validation.csv]

---

## Technologies & Tools

* Python
* Pandas & NumPy
* Scikit-learn
* TensorFlow / Keras
* Matplotlib & Seaborn
